## Interpretation and accounting

Fully strengthened passing generated groups: []. At least two are required for a continuation proposal, not an automatic P2 launch. Even both seeds passing is exploratory evidence only.

retrieval.json contains all fixed-score/random K curves using the first representation-feasible descriptors, never final retry descriptors. This is offline pool retrieval, not measured online acceleration. Failures consume candidate budget. A minimum from a partially evaluated pool is not a known optimum.

results.json retains all attempts, final and initial descriptors, representation/compilation fidelity, scores, tensor storage, retained dense-basis storage (not peak temporary allocation), build/verification and compilation times, process baseline/peak RSS and termination categories. Phase timing, input tensor files, QPY circuits and synthesis-start journals remain in each run directory. Generation and diagnostic-reference construction costs remain in the frozen manifest.
